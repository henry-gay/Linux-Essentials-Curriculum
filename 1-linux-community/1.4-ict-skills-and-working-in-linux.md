# 1.4 ICT Skills and Working in Linux

## **Objective**
This lesson covers essential ICT (Information and Communication Technology) skills and practical knowledge needed to work in a Linux environment. It aligns with the **Linux Essentials 010-160 exam** objectives and provides real-world examples to reinforce learning.

---

## **1. Introduction to ICT and Linux**
### What are ICT Skills?
- ICT (Information and Communication Technology) encompasses digital literacy, networking, security, and data management.
- In Linux, ICT skills include using the terminal, navigating file systems, managing software, and basic troubleshooting.

### Importance of Linux in ICT
- **Widely used**: Linux powers enterprise servers, cloud computing, embedded systems, and security infrastructures.
- **Essential for DevOps and System Administration**: Linux is the foundation of many DevOps tools and automation platforms.
- **Open-Source Advantage**: Customizable, scalable, and widely supported by the global tech community.

---

## **2. Navigating the Linux Desktop and Terminal**
### **Graphical User Interface (GUI) vs. Command Line Interface (CLI)**
| Feature | GUI | CLI |
|---------|-----|-----|
| Ease of Use | Intuitive, visual-based | Requires command knowledge |
| Flexibility | Limited customization | Highly customizable |
| Performance | Uses more system resources | Lightweight and efficient |
| Remote Access | Limited without extra tools | Easily accessible via SSH |

- Popular Linux Desktop Environments: GNOME, KDE, XFCE, Cinnamon.
- CLI is the preferred method for working with Linux in enterprise environments.

### **Essential Terminal Commands**
| Command | Description |
|---------|-------------|
| `pwd` | Print current directory |
| `ls` | List directory contents |
| `cd` | Change directory |
| `cp` | Copy files or directories |
| `mv` | Move/rename files or directories |
| `rm` | Remove files or directories |
| `mkdir` | Create directories |
| `rmdir` | Remove empty directories |
| `touch` | Create empty files |
| `cat` | View file contents |

**Practical Exercise:**
1. Open a terminal and navigate to your home directory.
2. Create a new directory, move into it, and create an empty file.
3. Copy and move files between directories.
4. List contents using different `ls` options (`ls -l`, `ls -a`).

---

## **3. Software Management in Linux**
### **Package Management Systems**
| Distribution | Package Manager | Commands |
|-------------|----------------|----------|
| Debian/Ubuntu | APT (Advanced Package Tool) | `apt update`, `apt install <package>` |
| RHEL/CentOS/Fedora | YUM/DNF | `dnf install <package>` |
| Arch Linux | Pacman | `pacman -S <package>` |

**Practical Exercise:**
1. Update your system’s package lists.
2. Install a basic utility (e.g., `htop`).
3. Remove an installed package.
4. Search for a package using the package manager.

---

## **4. Remote Access and Network Configuration**
### **Remote Access Tools**
| Tool | Purpose |
|------|---------|
| SSH (Secure Shell) | Securely access remote systems |
| SCP | Secure file copy between systems |
| Rsync | Synchronize files remotely |

### **Networking Basics**
| Command | Purpose |
|---------|---------|
| `ip a` | Display network interfaces |
| `ping` | Check network connectivity |
| `netstat -tulnp` | Show active network connections |
| `traceroute` | Show route to a remote host |

**Practical Exercise:**
1. Use SSH to connect to a remote machine.
2. Transfer a file securely using `scp`.
3. Check your system’s IP address and active connections.

---

## **5. File Permissions and Security**
### **Understanding Linux File Permissions**
| Symbol | Meaning |
|--------|--------|
| `r` | Read |
| `w` | Write |
| `x` | Execute |

### **Modifying Permissions**
| Command | Purpose |
|---------|---------|
| `chmod 755 file` | Change permissions using numeric notation |
| `chown user:group file` | Change file ownership |

**Practical Exercise:**
1. Create a file and modify its permissions.
2. Change file ownership and verify changes.

---

## **6. Summary & Key Takeaways**
- ICT skills in Linux include navigation, package management, remote access, and security.
- The command-line interface is essential for efficiency and automation.
- Understanding permissions and networking is critical for working in enterprise environments.
- Hands-on practice reinforces skills needed for Linux system administration.
