## **1.1 Linux Evolution and Popular Operating Systems**

### **Multiple-Choice Questions**
1. Who is credited with creating the Linux kernel?
    - A) Richard Stallman
    - B) Linus Torvalds
    - C) Dennis Ritchie
    - D) Bill Gates

2. What is the primary difference between Linux and UNIX?
    - A) Linux is open-source, while UNIX is proprietary
    - B) Linux is only used for desktop environments
    - C) UNIX is more modern than Linux
    - D) Linux and UNIX are identical

3. Which Linux distribution is known for its stability and is often used in enterprise environments?
    - A) Ubuntu
    - B) Arch Linux
    - C) Red Hat Enterprise Linux (RHEL)
    - D) Gentoo

### **True or False**
1. The Linux kernel is maintained by a single individual without external contributions. (T/F)
2. Debian is an example of a Linux distribution that follows a rolling release model. (T/F)

### **Fill-in-the-Blank**
1. The _______ project provides a collection of open-source tools that, when combined with the Linux kernel, create a complete operating system.
2. The first version of the Linux kernel was released in the year _______.

### **Scenario-Based Question**
You work for a company that is transitioning from Windows to Linux-based servers. They are unsure whether to choose Ubuntu Server or CentOS Stream. How would you explain the key differences between these two options?

## **1.3 Open Source Software and Licensing**

### **Multiple-Choice Questions**
1. What does the GPL (General Public License) require developers to do?
    - A) Keep their software proprietary
    - B) Release the source code and allow modifications
    - C) Prevent redistribution
    - D) Charge a mandatory fee for using the software

2. Which license is the most permissive?
    - A) GPL
    - B) MIT
    - C) Apache
    - D) BSD

### **True or False**
1. Copyleft licenses allow modifications but require that derivative works remain open-source. (T/F)
2. The MIT license does not allow commercial use of software. (T/F)

### **Fill-in-the-Blank**
1. The _______ license is often used by software projects that want to allow both open-source and proprietary use of their code.
2. Open-source licenses ensure that software can be freely used, modified, and _______.

### **Scenario-Based Question**
A startup wants to release its software as open-source but is concerned about competitors using their code without contributing back. Which license would best address this concern?
