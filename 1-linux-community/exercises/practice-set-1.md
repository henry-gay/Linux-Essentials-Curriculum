# Practice Set 1: Linux Community & ICT Skills

## **Objective**
This practice set is designed to reinforce key concepts from **Section 1: The Linux Community and a Career in Open Source**, aligned with the **Linux Essentials 010-160 exam**. Each section includes real-world scenarios, hands-on exercises, and thought-provoking questions to test comprehension.

---

## **1.1 Linux Evolution and Popular Operating Systems**

### **Scenario-Based Questions**
1. Explain how Linux evolved from UNIX. What are the key differences between UNIX and Linux?
2. Name three major Linux distributions and describe their primary use cases.
3. Why is Linux considered a preferred operating system for enterprise servers?
4. Compare and contrast Linux with proprietary operating systems like Windows and macOS.

### **Hands-On Exercises**
- Use `uname -a` to find information about your Linux kernel.
- Use `lsb_release -a` to determine your Linux distribution and version.
- Research the history of your Linux distribution and write a short summary.

### **Short Answer Questions**
1. What is the GNU project, and how is it related to Linux?
2. Who is Linus Torvalds, and what was his role in Linux development?
3. What does the term “distribution” mean in the Linux world?

---

## **1.2 Major Open Source Applications**

### **Scenario-Based Questions**
1. Your company needs an open-source alternative to Microsoft Office. Which application would you recommend and why?
2. Your team is setting up a web server. Which open-source software options can be used for this purpose?
3. What are the advantages of using open-source software over proprietary software?

### **Hands-On Exercises**
- Install LibreOffice on your system using the package manager (`apt`, `dnf`, or `pacman`).
- Use `vim` or `nano` to create and edit a text file.
- Install and configure an open-source web server (Apache or Nginx) and verify it is running.

### **Short Answer Questions**
1. Name three open-source web browsers and their key differences.
2. What is GIMP, and how does it compare to Adobe Photoshop?
3. Which open-source email clients are available for Linux users?

---

## **1.3 Open Source Software and Licensing**

### **Scenario-Based Questions**
1. Your company wants to modify and distribute an open-source application. Which licenses allow this?
2. What are the main differences between the GPL and MIT licenses?
3. Why do businesses prefer permissive licenses over copyleft licenses?

### **Hands-On Exercises**
- Find the license type of a software package using `apt show <package>` or `dnf info <package>`.
- Research and list five open-source projects and their licenses.
- Compare two different licenses and summarize their pros and cons.

### **Short Answer Questions**
1. What does the term “copyleft” mean in the context of open-source licensing?
2. What is the difference between proprietary, freeware, and open-source software?
3. How does the Creative Commons license differ from the GPL?

---

## **1.4 ICT Skills and Working in Linux**

### **Scenario-Based Questions**
1. You need to remotely access a Linux server. What tool would you use, and how does it work?
2. Your Linux system is running low on disk space. How can you identify large files and remove them?
3. Explain how Linux is used in DevOps, cloud computing, and cybersecurity.

### **Hands-On Exercises**
- Use SSH to log into a remote Linux machine.
- List all network interfaces on your system using `ip a`.
- Check system resource usage with `top` or `htop`.
- Install and use a package management tool (`apt`, `dnf`, `pacman`).

### **Short Answer Questions**
1. What is the difference between CLI and GUI in Linux?
2. How can you find and install software on a Linux system?
3. What is the purpose of environment variables in Linux?
